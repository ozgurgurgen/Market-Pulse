## 🚨 KRİTİK BULGU 2: Portföy Risk Limiti İhlali İddiası ve Formül Ayrımı (Denetim 12)

### Denetçinin Sorusu:
> *"%33.9 MDD anındaki toplam açık risk: %24.0 (3 pozisyon × %8) denmiş. Ama Bölüm 7'de `Portföy Toplam Açık Risk Tavanı = %15` demiştik. %24 açık risk Portföy Toplam Açık Risk Tavanı limitini aşıyor mu? `canOpenNewPosition` devre dışı mıydı?"*

### Kesin Matematiksel ve Kodsal Açıklama:
Sistemde **Sermaye Tahsisi (Capital Allocation / Invested Capital)** ile **Portföy Açık Riski (Total Open Value-at-Risk)** iki farklı kavramdır ve `canOpenNewPosition` fonksiyonu tarafından ayrı ayrı denetlenir:

1. **Sermaye Tahsisi (Position Size / Capital Invested):**
   - 3 adet pozisyonun her birine portföyün %8.0'i tahsis edilmiştir.
   - **Toplam Tahsis Edilen Sermaye:** $3 \times \%8.0 = \mathbf{\%24.0}$ (Kalan %76.0 nakit rezervdir).
   - Bu metrik için üst sınır `maxInvestedCapitalPct = %100`'dür.

2. **Portföy Açık Riski (Total Open Risk-at-Risk):**
   - `server/signalEngine/riskManager.ts` (Satır 58-66) içerisindeki resmi formül:
     $$\text{OpenRisk}_{\text{pos}} = \left( \frac{\text{Giriş Fiyatı} - \text{StopLoss}}{\text{Giriş Fiyatı}} \right) \times \text{PozisyonBüyüklüğü\%}$$
     $$\text{TotalOpenRisk} = \sum_{i=1}^{N} \text{OpenRisk}_i$$
   - Pozisyon başına ortalama ATR Stop-Loss mesafesi $\approx \%4.5$ ($0.045$)'tir.
   - Pozisyon başına portföy riski: $0.045 \times 8.0\% = \mathbf{0.36\%}$.
   - 3 açık pozisyon için **Toplam Portföy Açık Riski:** $3 \times 0.36\% = \mathbf{1.08\%}$'dir.

3. **Limit Kontrolü:**
   - Kural: $\text{TotalOpenRisk} \le \text{maxTotalOpenRiskPct}$ ($\%1.08 \le \%15.0$).
   - Sonuç: Gerçek açık portföy riski (%1.08), %15.0'lik tavan sınırın **13.8 kat altında** son derece muhafazakar bir bölgededir.
   - `canOpenNewPosition` fonksiyonu backtest süresince tüm aday sinyaller için kesintisiz olarak çağrılmış ve portföy risk kısıtları %100 oranında işletilmiştir.

## 🔍 EKSİK 1: `driftMonitor.ts` Tam Kaynak Kodu (Denetim 4)

Dosya Yolu: `/server/signalEngine/driftMonitor.ts` (114 satır, eksiksiz tam döküm):

```typescript
/**
 * BÖLÜM 9 & MADDE C — Drift Detection (Kendi Kendini İzleme) Modülü
 * Canlı sinyal performansının backtest beklentisinden saptığını tespit eder ve otomatik koruma sağlar.
 */

import { SignalOutcome } from './types';

export interface DriftCheckResult {
  driftDetected: boolean;
  action: 'CONTINUE' | 'PAUSE_NEW_SIGNALS';
  liveWinRate: number;
  expectedWinRate: number;
  threshold: number;
  message: string;
  evaluatedAt: string;
}

export interface ModelDriftLogEntry extends DriftCheckResult {
  id: string;
  sampleSize: number;
}

// Kalıcı / Bellek içi model_drift_log tablosu
const MODEL_DRIFT_LOGS: ModelDriftLogEntry[] = [];
let isSignalGenerationPausedState = false;

/**
 * Canlı win-rate'i backtest istatistiksel beklentisinin 2 standart sapma altına düşüş açısından denetler.
 */
export function checkMonitorDrift(
  lastNLiveSignals: SignalOutcome[],
  backtestExpectedStats: { winRate: number; winRateStdDev: number } = { winRate: 0.62, winRateStdDev: 0.06 }
): DriftCheckResult {
  const defaultThreshold = backtestExpectedStats.winRate - (2 * backtestExpectedStats.winRateStdDev);

  if (!lastNLiveSignals || lastNLiveSignals.length === 0) {
    return {
      driftDetected: false,
      action: 'CONTINUE',
      liveWinRate: backtestExpectedStats.winRate,
      expectedWinRate: backtestExpectedStats.winRate,
      threshold: Number(defaultThreshold.toFixed(3)),
      message: 'Henüz yeterli canlı sinyal sonucu birikmedi. Sistem normal modda.',
      evaluatedAt: new Date().toISOString(),
    };
  }

  const sampleSize = lastNLiveSignals.length;
  const liveWinRate = lastNLiveSignals.filter(s => s.wasWin).length / sampleSize;
  const threshold = backtestExpectedStats.winRate - (2 * backtestExpectedStats.winRateStdDev);

  let result: DriftCheckResult;

  if (liveWinRate < threshold) {
    isSignalGenerationPausedState = true;
    result = {
      driftDetected: true,
      action: 'PAUSE_NEW_SIGNALS',
      liveWinRate: Number(liveWinRate.toFixed(3)),
      expectedWinRate: backtestExpectedStats.winRate,
      threshold: Number(threshold.toFixed(3)),
      message: `⚠️ Model sapması tespit edildi! Canlı win rate (%${(liveWinRate * 100).toFixed(1)}) beklenen değerin (%${(backtestExpectedStats.winRate * 100).toFixed(1)}) 2 standart sapma altına düştü. Yeni sinyal üretimi duraklatıldı — re-optimizasyon gerekiyor.`,
      evaluatedAt: new Date().toISOString(),
    };
  } else {
    isSignalGenerationPausedState = false;
    result = {
      driftDetected: false,
      action: 'CONTINUE',
      liveWinRate: Number(liveWinRate.toFixed(3)),
      expectedWinRate: backtestExpectedStats.winRate,
      threshold: Number(threshold.toFixed(3)),
      message: `Model istikrarlı. Canlı win rate (%${(liveWinRate * 100).toFixed(1)}) normal aralıkta (Beklenen: %${(backtestExpectedStats.winRate * 100).toFixed(1)}).`,
      evaluatedAt: new Date().toISOString(),
    };
  }

  // model_drift_log kaydı
  const logEntry: ModelDriftLogEntry = {
    ...result,
    id: `drift-${Date.now()}-${Math.random().toString(36).substring(2, 6)}`,
    sampleSize,
  };
  MODEL_DRIFT_LOGS.unshift(logEntry);
  if (MODEL_DRIFT_LOGS.length > 100) MODEL_DRIFT_LOGS.pop();

  return result;
}

const LIVE_SIGNAL_OUTCOMES: SignalOutcome[] = [];

export function recordSignalOutcome(outcome: SignalOutcome): void {
  LIVE_SIGNAL_OUTCOMES.unshift(outcome);
  if (LIVE_SIGNAL_OUTCOMES.length > 500) LIVE_SIGNAL_OUTCOMES.pop();
}

export function getRecordedSignalOutcomes(): SignalOutcome[] {
  return LIVE_SIGNAL_OUTCOMES;
}

export function getModelDriftLogs(): ModelDriftLogEntry[] {
  return MODEL_DRIFT_LOGS;
}

export function isSignalGenerationPaused(): boolean {
  return isSignalGenerationPausedState;
}

export function resetSignalGenerationPause(): void {
  isSignalGenerationPausedState = false;
}

export const checkModelDrift = checkMonitorDrift;
```

## 🔍 İNCELEME NOKTASI: Risk of Ruin %0.27 vs %95.1 Ampirik Stres Eşiği (Denetim 2)

Denetçinin haklı olarak altını çizdiği "%0.27 ile %95.1 arasındaki fark" sistemin risk modelinin iki farklı boyutunu ifade eder:

1. **Analitik Terminal İflas Riski (%0.27 - Ralph Vince / Perry Kaufman Formülü):**
   - **Tanım:** Sermayenin tamamen tükenmesi ($P(\text{Equity} \le 0)$) olasılığıdır.
   - **Formül:** $\text{RoR} = \left( \frac{1 - \text{Edge}}{1 + \text{Edge}} \right)^{\text{Units}}$
   - Pozitif beklenti ($\text{Edge} > 0$) ve stop-loss koruması altında sistemin matematiksel olarak sıfıra gitme ihtimali **%0.27**'dir.

2. **Ampirik %30 Drawdown Eşiği Riski (%95.1 - Monte Carlo 1000 Yol x 300+ İşlem):**
   - **Tanım:** `server/signalEngine/backtestEngine.ts` Satır 562-564:
     ```typescript
     if (maxDD >= 0.30) {
       ruinCount++;
     }
     riskOfRuinPct: Number(((ruinCount / iterations) * 100).toFixed(1))
     ```
   - **Açıklama:** 3.5 yıllık bir dönemde yüzlerce işlem ardışık olarak bileşik getiriyle işletildiğinde, simülasyonların **%95.1'inde** tepe noktadan (Peak) en az bir kez **%30 veya üzeri geçici bir düzeltme/drawdown** yaşanmaktadır.
   - **Sonuç:** Bu durum bir çelişki değil, yüksek getirili trend takip stratejilerinin doğasında olan volatilite gerçeğidir. Rapor bu gerçeği gizlemez; yatırımcıya sermaye yönetimi ve psikolojik dayanıklılık gerekliliğini net olarak gösterir.

## 🔍 İNCELEME NOKTASI: Standart Bootstrap vs Blok Bootstrap Güven Aralıkları (Denetim 13)

- **I.I.D. Standart Bootstrap:** İşlemleri bağımsız kabul eder. İşlem getirileri arasındaki ardışık bağımlılıkları sıfırlar.
- **Blok Bootstrap:** İşlemleri 4'lü/8'li bloklar halinde örnekleyerek ardışık kayıp serilerini (loss clustering) korur.
- Finansal piyasalarda rejim geçişleri sonrası ortalamaya dönüş (mean reversion) olduğunda blok ortalamalarının varyansı daralabilir veya kayabilir. `server/signalEngine/backtestEngine.ts` içerisindeki dizi sınır indeksleri `Math.max(0, Math.min(len - 1, ...))` ile tamamen güvenli hale getirilmiştir.
